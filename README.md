# Emberwatch updates

Public compiled game updates and Android alpha downloads for Emberwatch. Source code is maintained privately.

Install the latest APK from Releases. Compatible installed apps check the signed manifest automatically on launch, foreground, and every five minutes while open. Downloaded game updates apply after leaving and reopening the app. Native capability changes require a new native build. iOS binaries require Apple signing and are not yet available.

Only the app's pinned signing key can authorize updates. No GitHub token is included in the app. Do not install altered APKs from other sources.
